## Material limits

- **Cerebras:** Current Zacks FY2026/FY2027 consensus was observed after the
  cutoff, with no FY2028 value and no retained historical publication vintage.
  It stays outside the dated chart. This is an evidence gap, not a claim that
  no analysts cover Cerebras. [Retained access and consensus evidence](../../data/reviewed/expansion_20260914/cerebras_gap.json).
- **Palantir:** The retained August report repeats a model dated 4 May, 130
  days before the cutoff. The model date is not changed to August. Shorter age
  limits can remove its target.
- **Nebius:** The August report changes EPS but keeps a 13 May model header.
  Changed values enter only from 13 August. The old header remains the age
  reference. This conflict is unresolved and appears in the app. Negative
  annual EPS stays negative; the engine does not replace it with zero.
- **Oracle:** A report printed on 11 September repeats the June model. Its
  assumed availability is 12 September, so the cutoff uses the prior report.
- **TSMC:** The source directly states USD per ADR. No TWD forecast is converted
  using an inferred exchange rate. The source does not identify an adjusted,
  reported, basic, or diluted basis. This publisher composite is excluded from
  named-analyst ensembles. Its reported IFRS USD/ADS results are separately
  translated by the issuer for reader convenience; they are not declared
  comparable to this forecast series.
- **SpaceX:** Listed history starts in June. Its analyst reports revise
  historical earnings and forecast values. The precise consolidation scope
  remains unresolved. Annual reported results predate its IPO and include xAI
  and X under common-control accounting.
- **Reported results:** Values retain the filing's share units and accounting
  basis. They are not normalized for later splits. The retained notes identify
  Arista's older share basis, Cerebras's pre-IPO capital structure, and Nebius's
  discontinued operations. Earlier Yandex results are excluded from Nebius.
- **Availability:** The new dated forecasts use report date plus one calendar
  day as an unverified assumption. Retrieval occurred on 13 September UTC /
  14 September Amsterdam. No current capture is backdated. None of this new
  history is admitted as verified availability. The readiness assessment is
  still `not_ready` for a historical strategy study.
- **Original archive:** The original 10 company forecast objects and their
  provenance are preserved. Their missing upstream PDF archive is still
  missing. New downloads are locally retained and hash-checked.

## Reproduce the import

Running the app and tests needs only this checkout. Re-running the stock import
also needs the separate `data/collection/expansion_20260914_*` source archive,
staged prices, and preserved base listed below. These original downloads are
excluded from Git under the existing archive policy. The small reviewed inputs
are included in `data/reviewed/expansion_20260914/`.

From the repository root, using the app's Python environment:

```sh
.venv/bin/python scripts/import_expansion.py \
  --base data/refresh/expansion_20260914/before/web/public/data/dashboard.json \
  --price-directory data/collection/expansion_20260914_market/prices \
  --evidence data/reviewed/expansion_20260914/hardware.json data/reviewed/expansion_20260914/platforms.json \
  --actuals data/reviewed/expansion_20260914/actuals.json \
  --output data/refresh/expansion_20260914/dashboard.json \
  --publish
node scripts/build_backtest_readiness.mjs
node scripts/build_gap_map.mjs
```

This command validates local hashes, currencies, dates and fiscal periods before
publishing. It does not redownload sources or replace original forecast series.
Prior files are preserved in the run's `before/` directory. Reproduction uses
the retained inputs, not mutable current pages. The upstream full refresh
remains unsuitable while its original archive is absent.
